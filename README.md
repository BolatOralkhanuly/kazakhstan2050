# Мой Казахстан 2050 — сайт с интерактивной картой и опросом

## Что есть в проекте
- Адаптивная главная страница.
- Интерактивная карта на OpenStreetMap с 6 точками Казахстана.
- Опрос по региону и приоритетам будущего.
- Сохранение ответов в SQLite и отображение сводных результатов.
- Подготовлено для бесплатного учебного размещения.

## Запуск на компьютере
1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Выполните:
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
4. Откройте `http://127.0.0.1:5000`.

## Публикация
Загрузите файлы проекта в GitHub. Затем создайте Web Service на Render, подключите репозиторий и укажите:
- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn app:app`

Добавьте `gunicorn` в requirements.txt перед публикацией. Для постоянного хранения SQLite на бесплатном хостинге проверьте актуальные условия диска/хранилища; без постоянного диска база может сбрасываться при перезапуске. Для демонстрационного проекта это допустимо, но для устойчивой базы лучше подключить PostgreSQL.

После публикации у вас появится публичный HTTPS-адрес вида `https://имя-проекта.onrender.com`. Именно этот адрес нужен для рабочего QR-кода.
